初期配置クイズ

はじめの村をどこに置くかで、ゲームの大半の収入が決まります。A〜D のどこに置くと一番勝ちやすいか、AIどうしの対局で確かめた答えと比べてみましょう。

正解の決め方

このサイトのAI（ふつう）4人で初期配置を進め、問題の場面で止めます。AIの評価で上位の置き場所それぞれについて、そこに村を置いてから最後までAIどうしで何百局も打ち、その席の勝率を比べました。選択肢は、一番勝った場所と、それよりはっきり勝率が低かった場所（差が測り方のぶれの2倍以上）から選んでいます。

AIどうしの勝率なので、人どうしでは答えが変わることもあります。数字や資源の数の考え方はルール入門、全体の傾向はデータで見るにあります。

「島の交易路」はこの研究のためのオリジナルの名前です。AI とページのソースは GitHub にあります。
