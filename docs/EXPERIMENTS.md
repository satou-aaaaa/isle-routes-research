# 実験の記録

新しい順。勝率は4人戦で、基準は 25%。席は入れ替えて同じ盤を全員が全部の席で打つ（`scripts/run_match.py`・`scripts/gate.py`）。

## 2026-11-12 最初のAI（貪欲AI）と重みの合わせ方

| 対戦 | 対局数 | 結果 |
|---|---|---|
| 貪欲AI 1人 対 ランダム3人 | 100 | 貪欲AIが全勝、平均 10.1 点・81.5 手番で決着 |
| 貪欲AI 4人どうし | 100 | 席ごとの勝ち数 20・32・28・20、平均 89.5 手番 |
| 回帰で学んだ重み 1人 対 手の重み3人 | 200 | 勝率 0.5%（大きく弱い）→ 不採用 |
| SPSA で80回合わせた重み 1人 対 手の重み3人 | 400 | 勝率 26.8%（95%の幅 22.4〜31.1%）→ 差がはっきりせず不採用 |

- 貪欲AI（`GreedyAgent`）は評価関数で1手先だけを見る。盗賊は「勝ちに近い相手の産出を止め、自分にはかけない」目安で置く。
  発展カードを買う手は山札をのぞかず、得点カードの割合（5/25）で平均をとる。
- 回帰（各手番の特徴量 → 勝ったか、ロジスティック回帰、約5.4万件）は、勝っている人ほど大きい「近くの空き頂点の価値」に
  大きな重みが付き、村を建てるより空き頂点を残す手を選ぶようになって弱くなった。勝ち負けとの相関は、手を選ぶための重みにはならない。
- SPSA（`scripts/tune_spsa.py`、1回32局×80回）は、1回の勝率差のぶれ（±0.17ほど）が大きく、80回では足りない。
- 次: エンジンを速くして、サイコロを引いて先を読む探索（MCTS）に進む。重み合わせは対局数を増やして自己対戦ループで続ける。
