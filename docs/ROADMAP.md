## 段階

1. **準備**（PR #1、済み）: リポジトリ・CI・確認コマンド・ルールエンジンの初版とテスト。
2. **ルールエンジンを固める**: 対局の記録（JSONL・seed で再現）と席を入れ替えた成績は済み（PR #2）。次は高速化。
3. **最初の強いAI**: 貪欲法（PR #2、ランダム相手に100局全勝。docs/EXPERIMENTS.md）→ 評価関数＋MCTS（サイコロ・隠れたカードは引いて読む）、初期配置の専用学習。
   次へ進む条件: Catanatron の AlphaBeta を含む4人戦で、勝率25%をはっきり上回る（席の入れ替え・同じ出目の順で比べる）。
4. **自己対戦ループ**: carcassonne-research と同じ毎時の改善とチャンピオン交代。
5. **公開サイト**: ルール入門・AIと対戦（JS移植）・初期配置クイズ・コツ集・データ。日英2言語、スマホとPCで点検。
6. **交換を足す**: 1対1の交換の申し出と受け方。対戦ページでも人がAIと交換できるようにする。

## ルールの要点（エンジンが従う数値）

- 六角形19枚（森4・丘3・牧草地4・畑4・山3・砂漠1）、数字チップ18枚（2〜12、7なし）、港9（3:1が4、各資源の2:1が1）。
  地形と発展カードの内訳はルールブックの本文に数の明記がなく、部品の数として広く知られる値を使っている。
- 盤はランダムに並べ、6と8は隣り合わせない。
- 10点（自分の手番で）で勝ち。村1点・街2点・最長の道（5本以上）2点・最大の騎士（3枚以上）2点・得点カード1点。
- 建てる費用: 道＝木材＋れんが、村＝木材＋れんが＋羊毛＋小麦、街＝小麦2＋鉱石3、発展カード＝羊毛＋小麦＋鉱石。
- 駒: 道15・村5・街4。発展カード25枚（騎士14・得点5・道づくり2・収穫2・独占2）。
- 7: 産出なし、8枚以上持つ人は半分（切り捨て）捨てる、盗賊を動かして隣の人から1枚を無作為に奪う。
- 銀行が足りない資源は、もらう人が1人なら残りを、2人以上なら誰ももらえない。
- 発展カードは1手番1枚、買った番には使えない（得点カードは除く）。騎士はサイコロの前にも使える。
- 出典: 公式ルールブック 2015年版（英語）https://cdn.shopify.com/s/files/1/0024/8617/3749/files/catan-25th-rules_eng-200313.pdf 、
  公式FAQ https://www.catan.com/faq/basegame （Q33・Q34: 銀行が足りないとき）
